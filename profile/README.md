### Nexus Terminal

A market-intelligence terminal for macroeconomic data, liquidity, positioning, regulatory filings, prediction markets, and live news. Includes an AI research assistant and an HTTP API with MCP support.

[Terminal](https://nexus.omnific.dev/) · [Documentation](https://docs.omnific.dev/)

The core repositories are private. The public repositories contain reusable templates and tooling.
